# Alien Invasion Text-Based Game

This is a Python-based text adventure game where the player must explore a house, collect items, and defeat an alien in the basement.

## Game Description

Aliens have invaded Earth, and one has taken residence in your house! To defeat it, you must find six essential items scattered throughout the rooms:

* **FLASHLIGHT:** From the Kitchen, to see in the dark.
* **ALUMINUM HELMET:** From the Main Bedroom, to block alien mind-reading.
* **EAR PLUGS:** From the Guest Bedroom, to tune out high-pitched alien noises.
* **BODY SUIT:** From the Guest Closet, for protection.
* **RAY-GUN:** From the Garage, to fight the alien.
* **GAS MASK:** From the Living Room, to avoid toxic air.

Navigate the house using directional commands, collect the items, and confront the alien in the Basement.

## How to Run the Game

1.  **Python 3.10:** Ensure you have Python 3.10 installed on your system. You can check this by opening a terminal or command prompt and typing `python --version` or `python3 --version`.
2.  **Save the File:** Save the Python code (`Azcue_Soto_Python_Project.py`) to your local machine.
3.  **Open Terminal/Command Prompt:** Open your computer's terminal or command prompt.
4.  **Navigate to Directory:** Use the `cd` command to navigate to the directory where you saved the Python file. For example, if you saved it in a folder named "MyGames" on your Desktop, you would type:
    ```bash
    cd Desktop/MyGames
    ```
5.  **Run the Game:** Execute the game by typing the following command and pressing Enter:
    ```bash
    python Azcue_Soto_Python_Project.py
    ```

## Controls

* **Movement:** Use the following commands to move between rooms:
    * `go North`
    * `go South`
    * `go East`
    * `go West`
* **Collect Items:** To pick up an item in the current room, type:
    * `get <ITEM NAME>` (Replace `<ITEM NAME>` with the actual item name, e.g., `get RAY-GUN`)

## Game Flow

The game starts in the Main Hallway.  Explore the rooms, collect all six items, and then head to the Basement to face the alien.  You win if you have all the items; otherwise, the alien defeats you!
